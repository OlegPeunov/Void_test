# Исправления ProjectBuilder

| Проблема / симптом | Причина | Решение |
| --- | --- | --- |
| Выбор услуги сбрасывался, количество не менялось, кнопка «Добавить» оставалась недоступной. | Значения хранились в локальных переменных; их изменение не вызывало рендер, а при рендере они создавались заново. | Выбранная услуга, количество и список перенесены в `useState`; поля обновляют состояние через сеттеры. |
| Добавление не обновляло список; изменения могли теряться. | `push` и изменение `existing.quantity` мутировали массив и вложенную строку без обновления состояния React. | Функциональные обновления `setSelectedServices` используют актуальный список. Добавление создаёт новый массив, увеличение количества — новую строку через spread и `map`. |
| Удаление не обновляло интерфейс. | `splice` менял локальный массив, не уведомляя React. | Функциональное обновление состояния с `filter` удаляет строку по `service.id`, создавая новый массив. |
| Итог не отражал изменения списка. | Изменения локального массива не вызывали рендер; итог оставался значением, вычисленным до них. | `reduce` вычисляет итог из текущего состояния списка при каждом рендере. Отдельного состояния итога и `useEffect` нет. |
| Пустое или некорректное количество могло попасть в список. | `Number('')` даёт `0`, а атрибуты `min`/`max` сами по себе не запрещают вызов обработчика; проверки целого числа не было. | Количество хранится строкой, поэтому поле можно очистить. Для добавления требуется `Number.isInteger` и диапазон 1–10; пустая строка преобразуется в `0` и отклоняется. Кнопка отключается при некорректном вводе, и та же проверка выполняется внутри `addService` до обновления списка. |

## Дополнительное улучшение

Сравнение услуг по ссылке заменено сравнением по `service.id`. В исходном примере ссылки на объекты стабильны и сравнение работало; это улучшение устойчивости при возможном пересоздании объектов услуг, а не отдельный баг исходного примера.

## Допущение об ограничении количества

Диапазон 1–10 включительно относится к количеству **за одно добавление**, а не к суммарному количеству услуги. Например, добавления 10 и 3 единиц одной услуги дают одну строку с количеством 13. Пустой ввод, 0, отрицательные числа, дробные числа, значения больше 10 и нечисловой ввод не добавляются в список.
