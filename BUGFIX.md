# Что исправлено

1. **Состояние компонента.** Выбранная услуга, количество и список хранились в обычных переменных. Их изменение не вызывало перерисовку, а при следующем рендере значения сбрасывались. Теперь они хранятся в `useState`.

2. **Добавление и удаление.** `push`, `splice` и `existing.quantity += quantity` меняли массив и объекты напрямую. Теперь обновления идут через `setSelectedServices`: для добавления и удаления создаётся новый массив, для изменения количества — новый объект строки. Обновление получает предыдущий список, поэтому повторное добавление прибавляет количество к текущему.

3. **Итоговая стоимость.** Итог не обновлялся, потому что изменения списка не вызывали перерисовку. Теперь сумма считается из текущего списка при каждом рендере.

4. **Проверка количества.** Атрибуты `min` и `max` не запрещали добавление через обработчик, а пустое поле превращалось в `0` после `Number('')`. Теперь перед добавлением проверяется целое число от 1 до 10. При некорректном вводе кнопка отключена. Значение поля хранится строкой, чтобы его можно было очистить.

Услуги сравниваются по `id`. В исходном коде сравнение по ссылке работало, поскольку объекты брались из одного массива. Сравнение по `id` сохранит это поведение и при пересоздании объектов.

Ограничение 1–10 относится к одному добавлению. Общее количество услуги может быть больше 10: например, после добавления 10 и 3 единиц в строке будет 13.
