# Void_test

Тестовое задание на React 18 и TypeScript. Сборка — Vite.

## Запуск

Нужны Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Открыть в браузере: http://127.0.0.1:5173/.

## Сборка

```sh
npm run build
```

Команда проверит типы и соберёт проект в папку `dist`.
Посмотреть готовую сборку локально:

```sh
npm run preview
```

Описание исправлений — в [BUGFIX.md](BUGFIX.md).
