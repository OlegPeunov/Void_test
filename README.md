# Void_test

Минимальный проект на Vite, React 18 и TypeScript для поэтапного выполнения тестового задания.

## Установка

Требуется Node.js 24 LTS и npm. Зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
```

## Запуск

```sh
npm run dev
```

Адрес: http://127.0.0.1:5173/ (порт фиксирован; если он занят, Vite сообщит об ошибке).

## Проверка типов и сборка

```sh
npm run build
```

Команда проверяет TypeScript и создаёт production-сборку в `dist/`.

## Просмотр сборки

```sh
npm run preview
```

По умолчанию: http://127.0.0.1:4173/. Если порт занят, фактический адрес будет указан в терминале.
