# Void_test

Минимальный проект на Vite, React 18 и TypeScript для поэтапного выполнения тестового задания.

## Установка

Требуется Node.js 24 LTS и npm. Зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
```

## Запуск

```sh
npm run dev
```

Адрес: http://127.0.0.1:5173/ (порт фиксирован; если он занят, Vite сообщит об ошибке).

## Проверка типов и сборка

```sh
npm run build
```

Команда проверяет TypeScript и создаёт production-сборку в `dist/`.

## Просмотр сборки

```sh
npm run preview
```

По умолчанию: http://127.0.0.1:4173/. Если порт занят, фактический адрес будет указан в терминале.

## Поведение компонента

Выберите услугу, введите целое количество от 1 до 10 и нажмите «Добавить».
Повторное добавление той же услуги увеличивает количество существующей строки.
Ограничение 1–10 относится к одному добавлению: количество в строке может превышать 10.
При пустом или некорректном количестве кнопка «Добавить» недоступна; обработчик также проверяет ввод.
Кнопка «Удалить» удаляет соответствующую строку. Итог пересчитывается из текущего списка при рендере.
Редактирование количества непосредственно в таблице не предусмотрено.

Причины и решения исправленных проблем описаны в `BUGFIX.md`.
Интерфейс и оформление исходного компонента сохранены. Дополнительные библиотеки не используются.
